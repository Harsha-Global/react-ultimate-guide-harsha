# Solution explanation

Cancellation targets only the saved record's detail entry. Once it finishes, setQueryData receives the complete server response. Invalidating the list family lets the real application fetch lists whose membership, ordering or totals may have changed. The final await keeps this helper pending through that refresh step. A rejected cancellation stops execution before a replacement is written. The grader verifies calls, data and asynchronous ordering with a supplied test double; real request and cache behavior is demonstrated in the lecture project.
