The scale check verifies query results over 10,000 fixture records. It is not a timing benchmark. The normal browser API still serves the original four samples in pages of two or four rows.

Browser checks:
- Save studio, browse travel, apply the saved view, then use Back.
- Reload /?q=travel with saved studio: travel wins. Open / with no managed parameters: studio restores once. Clear search: it stays cleared. Check /?q= and /?page=banana.
- Select rows on different pages; sorting preserves selection, search and accepted saves clear it.
- Change Table density and overview visibility independently from the search.
- Use Tab/Shift+Tab, the skip link, table scroll region, row menu and editor. Check initial focus, trapped dialog focus, Cancel and restored row/search focus.
- Reject a duplicate name, retain its draft, and show focused field feedback. Stop the API for a failed save; restore it and retry the retained draft. Use api:slow separately for pending Escape protection, then restart the regular API.
- Fail an uncached list request and retry after restoring the API. Fail a refresh after existing rows were shown; retain those rows with the last-successful-result notice, then retry.
- Check Light/Dark, phone/tablet/desktop layouts, locale and review time zone. Currency remains USD; this guided main does not persist the optional display-format assignment choices.
- Open /motion-check.html?reduce=0. Compare its normal animation with Simulate reduced motion: the latter reports transform none and opacity 1. This is the inherited JavaScript preference fixture. It does not emulate CSS media queries; inspect the motion-safe CSS branches separately.
