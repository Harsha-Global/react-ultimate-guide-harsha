# Admin Workspace — an accessible editing dialog with focus restoration

The Admin Workspace project presents the product editor in a dialog. src/components/ProductActions.tsx gives each Actions button the stable id product-actions-<product id> and passes its trigger element to onEdit once the menu has closed; src/components/ProductTable.tsx forwards the product and that trigger. src/App.tsx keeps the trigger in an editTrigger ref and, in restoreEditFocus, waits one animation frame and looks up the current button by its id with document.getElementById: an enabled button receives focus, otherwise the search input does. src/components/ProductEditor.tsx wraps the existing form in a controlled Dialog (DialogContent with a maximum height and vertical scrolling, DialogTitle and DialogDescription, no close icon): opening focuses the name field, closing calls onRestoreFocus, a click outside never dismisses it, and Escape or a close request is ignored while a save is pending. The form's schema, field errors, retained rejected draft and pending buttons are unchanged. package.json adds the api:slow script for server/slow-api.mjs.

## Run

Copy the project into your React workspace (for example C:\react\admin-workspace-project) and open it in VS Code. In one terminal run `npm ci`, then `npm run api` (the local catalog service on http://127.0.0.1:5191, in memory: a restart restores the four sample products). In a second terminal run `npm run dev` and open http://127.0.0.1:5190 (stop any other app using ports 5190 or 5191 first, and use the same 127.0.0.1 address throughout: localhost is a different browser-storage origin). Validate with `npm run lint` and `npm run build`.
