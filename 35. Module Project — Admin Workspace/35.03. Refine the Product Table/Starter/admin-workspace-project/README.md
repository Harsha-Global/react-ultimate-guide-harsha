# Admin Workspace — the responsive workspace shell

The Admin Workspace project with the client's visual frame. src/index.css is the supplied workspace stylesheet (the Tailwind imports and theme tokens, the warm light palette with the deep blue primary, separate dark-theme values, the local Manrope and DM Sans fonts, the compact-density rules, a restrained header shadow and a visible focus outline for the catalog heading). src/components/WorkspaceHeader.tsx renders the header: a SHOPFRONT / Admin link to the catalog heading on the same page, the local-demo notice and the catalog introduction, in an inner grid that gives the received themeControl (a ReactNode) its own column from the small-screen breakpoint. src/App.tsx renders WorkspaceHeader with the existing labelled theme select as themeControl, adds a visually hidden Skip to catalog link before it and tabIndex={-1} on the catalog heading, and keeps the overview and catalog in their responsive grid (min-w-0 on the table's parent, so the table scrolls inside its own region).

## Run

Copy the project into your React workspace (for example C:\react\admin-workspace-project) and open it in VS Code. In one terminal run `npm ci`, then `npm run api` (the local catalog service on http://127.0.0.1:5191, in memory: a restart restores the four sample products). In a second terminal run `npm run dev` and open http://127.0.0.1:5190 (stop any other app using ports 5190 or 5191 first, and use the same 127.0.0.1 address throughout: localhost is a different browser-storage origin). Validate with `npm run lint` and `npm run build`.
