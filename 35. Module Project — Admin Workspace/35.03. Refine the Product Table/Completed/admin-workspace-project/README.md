# Admin Workspace — a controlled catalog toolbar and a precise selection count

The Admin Workspace project with its search controls in their own component. src/components/CatalogToolbar.tsx receives the current query, onQuery, the search input reference, onReset, whether sorting is active and onClearSorting; it renders the labelled search input (maxLength 60, its value from the query prop), Clear search and Clear sorting (each disabled when there is nothing to clear) and, only while the query has text, a summary that renders the query as ordinary React text. src/App.tsx renders CatalogToolbar with the values from useCatalogView and the existing reset and clear-sorting handlers (the URL stays the single owner of the search; no new state), and no longer imports Input and Label. src/components/ProductTable.tsx counts selected rows with Object.values(rowSelection).filter(Boolean).length, so an ID mapped to false is not counted; selection still follows product IDs across pages and sorting and clears when the search changes or a save is accepted.

## Run

Copy the project into your React workspace (for example C:\react\admin-workspace-project) and open it in VS Code. In one terminal run `npm ci`, then `npm run api` (the local catalog service on http://127.0.0.1:5191, in memory: a restart restores the four sample products). In a second terminal run `npm run dev` and open http://127.0.0.1:5190 (stop any other app using ports 5190 or 5191 first, and use the same 127.0.0.1 address throughout: localhost is a different browser-storage origin). Validate with `npm run lint` and `npm run build`.
