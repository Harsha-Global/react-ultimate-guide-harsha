# Forms & Route Actions

`routed-directory` is the completed source recorded in this lecture. It adds an editable employee draft, a router Form, route-action validation, a full PUT update, inline save results and disabled controls during the save. Successful saves stay on the edit page in this checkpoint.

The API starts with sample employees. The browser action reads and validates submitted fields; the separate API also validates and stores the update. Reloading the edit page reads the saved employee. Restarting the API restores its sample data.

The project includes its styles, local fonts and licenses. The supplied current reference and styles are included separately. No narration, capture, production dependency or later lecture source is included.
