# ShopFront Checkout — v1

## Open the design in Figma

1. Download `ShopFront Checkout Design Kit.fig` from this folder.
2. On Figma's file browser, choose **Import** and select that file.
3. Open the imported file and select **v1 - Original client brief** in the Pages list.

The design kit contains both the original client brief and the revised checkout design. If you have already imported the kit, use the same file and select the revised page when the revised checkout design is introduced. You do not need to recreate the designs or export anything.

Use the desktop, mobile and feedback-state designs as references while following the React lessons. The PDF and PNG files are also included for convenient viewing.
