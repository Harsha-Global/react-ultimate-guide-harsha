# ShopFront

The ShopFront catalog project: shareable catalog filters and pagination, product pages, the bag, delivery preferences and the inventory editor.

Run `npm ci`, then `npm run api` and `npm run dev` in separate terminals; the app runs on port 5185 and the local API on port 4185. Run `npm run api:reset` to restore the sample products. The browser's saved bag and delivery preferences are separate from the API data.
