# 13.07. Direct Links & Router Choices

`routed-directory` is the completed BrowserRouter app. `Demonstrations/hosting/server.mjs` serves its production build in plain and application-fallback modes. `Demonstrations/hash-router/routed-directory` is the isolated HashRouter alternative. Keep the main app unchanged when comparing these choices.

These local examples illustrate hosting behavior; they do not deploy an application. The setup notes explain the shared API, build commands, direct-link and reload comparisons. Choose your real host's documented rewrite/fallback configuration before deployment.
