# Routed directory — Metadata, Focus & History

Use Node.js 22.22.0 or newer. Open the routed-directory folder and run `npm ci`.

Run `npm run api` in one terminal and `npm run dev` in another. Open http://127.0.0.1:5183. The API runs on port 4183 and resets the sample employees when restarted.

This completed project includes page titles and descriptions, a keyboard skip link, and focus management on pathname changes. Query edits retain input focus. Navigate with the keyboard and use browser Back/Forward to inspect the behavior.

Use `npm run check`, `npm run lint`, and `npm run build` to validate the project.
