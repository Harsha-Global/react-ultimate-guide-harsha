# Product Explorer - v2 wireframes

Open `Product Explorer - v2.fig` in Figma to explore the complete editable design. This one file contains all 4 frames in the **Client change - v2** page; you do not download each frame separately. The PDF and individual PNG files support offline reference. SVG files preserve the vector source.

## Import into Figma

1. Sign in to your own Figma account and open Drafts. A solo Starter account is sufficient for this handoff; no collaborators or shared folder are required.
2. Choose **More → Import → Import from computer** in the file browser, then select `Product Explorer - v2.fig`. If the interface changes, use its file-browser Import action.
3. Open the imported design, select the named page, and expand the outer **Frame** in Layers to find the screen frames.
4. Select a screen frame and use **Zoom to selection**. Zoom into controls, cards, details, or the behavior notes as needed.

## Read the requirements alongside the design

Use Client Change.md in this lecture and the original brief from 07.01. CR-01 adds In stock only while preserving search, category, and selection. Details are connected in 07.04; these frames show the guided target.

These are static wireframes with behavior notes, not a clickable prototype. The running app and written acceptance checks demonstrate interactions. The native design uses editable Figma text and vectors. Figma imported its text as Inter; the application CSS retains Arial. Text metrics may differ slightly between the design, PDF/PNG references, and running browser; follow Visual Specification.md for implementation values.
