# Setting the Environment

The completed application is the exact source demonstrated in the video.

- Starter/admin-workspace: the supplied minimal starter; copy the whole folder into your React workspace (for example C:\react\admin-workspace) as in the lecture.
- Completed/admin-workspace: the project at the end of this lecture. Keep it for the next lecture.

## Run

Copy the project into your React workspace (for example C:\react\admin-workspace) and open it in VS Code. In its terminal run `npm ci`, then `npm run dev`, and open http://127.0.0.1:5190 (stop any other app using port 5190 first). No API or account is needed. Validate with `npm run lint` and `npm run build`.

## Try it

Run `npm run dev` and open http://127.0.0.1:5190: the pale page, the heading sizes and the rounded setup panel come from the utility classes. Make the window narrower (or use the browser's device toolbar at 390 px): the text stays inside the width. `npm run build` writes the production build.
