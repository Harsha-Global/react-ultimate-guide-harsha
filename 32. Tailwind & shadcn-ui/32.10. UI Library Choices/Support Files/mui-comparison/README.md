# Material UI comparison

This separate React/TypeScript/Vite project keeps the main Admin Workspace checkpoint unchanged. Use Node.js24.21.0 and `npm ci`, then `npm run dev`. Open http://127.0.0.1:5192.

Material UI9.5.0 uses Emotion in this example. The same React Hook Form7.89.0/Zod4.6.5 validation from the guided course owns the draft. TextField receives registration's ref through inputRef. The preview is local; there is no API request or persistence.

Try blank/negative/zero stock, inspect error labels and focus, submit valid values, reset and switch themes. Check keyboard use and a390px viewport. Run `npm run build` and `npm run lint`.

The main course project continues from the Form Component Integration lecture. This comparison is not a migration or a requirement to combine two UI libraries in the main app.
