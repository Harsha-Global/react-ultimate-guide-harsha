# Narrow the Booking Kind

Complete requiredPlaces. An individual booking needs one place. A group booking needs one place for each attendee currently in its draft. Narrow with the kind property before reading attendees.

Do not add attendees to the individual type or use an assertion to pretend both shapes have the same fields. This function calculates the count from a typed editing draft. Submission validation, including the group-size limits, is performed separately at the input boundary.
