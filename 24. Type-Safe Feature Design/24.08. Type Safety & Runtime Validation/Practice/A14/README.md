# Add a Group Contact Rule

Read Assignment.md. Start with Starter/booking-studio; keep Solution/booking-studio separate until after your attempt. Each is a complete application.

Run npm run api:slow and npm run dev in separate terminals. Open http://127.0.0.1:5210. Run npm run verify:group-contact in another terminal using that same variant. It resets the local practice data; run it before independent browser checks, not during a pending booking.

Install using `npm ci`. Run `npm run build` and `npm run lint` as well as the stated behavior checks. The solution explanation and manual rubric are in this folder.
