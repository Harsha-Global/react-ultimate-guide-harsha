# Cancellation & Request Races

Open `employee-directory` for the completed 12.07 checkpoint. To reproduce the lesson edits, begin from completed 12.06; this package supplies no separate Starter. Follow Setup.md to install and run the local API and Vite. API data is in memory and resets on restart. Prepared Styles, the two concept reference images and the student references are included.

Select Avery to fetch one employee object. Select Avery then Maya quickly under slower network conditions: Maya must remain selected after requests settle. Switch DevTools Network offline and select an employee; the list remains available while the detail panel reports failure. Restore the connection and select the same employee to retry. Canceled requests are not user-facing failures.
