# Migrating the App to Axios

Open `employee-directory` for the completed, recorded 12.11 checkpoint. Begin from completed 12.10 to perform the lesson edits. Axios is optional; the earlier Fetch implementation remains valid, and later course projects use Fetch by default. This checkpoint installs Axios 1.20.0, preserves the public API-function contracts and includes list, detail, create, replace, patch and delete behavior. Follow Setup.md. Supplied styles and student references are preserved. The API stores data in memory and resets on restart.
