# Fetching Data in React

The root employee-directory is the exact completed12.05 checkpoint. Starter/employee-directory is the exact unchanged12.04 shell, for following the lesson. Use only one copy on the development ports. Follow Setup.md to start the API and Vite app. The supplied stylesheet is already installed in the completed project; Styles contains the same file for the starter.

This lesson adds the typed employee API, validates external data, and connects it to React state with Effect cleanup. The ignore flag prevents obsolete state updates; it does not cancel requests. Reference files, Thought Checks and Changes.diff support review.

Dependencies, build output and lecture-production media are excluded.
