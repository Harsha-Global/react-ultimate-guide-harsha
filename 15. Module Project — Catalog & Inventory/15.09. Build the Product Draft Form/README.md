# Build the Product Draft Form

The completed checkpoint is `product-explorer`; begin with `Starter/product-explorer` to follow along. Continue one working app and use the completed source for comparison or recovery.

This checkpoint defines editable product inputs, draft values and validation. The editor loads a product into controlled fields. Save changes is disabled, the ordinary form prevents submission, and Cancel returns to inventory without changing the API record. The loader and product detail page retain their existing behavior.

Use Setup.md for the supplied runtime and Reference.md for source and API links. Resources contains the supplied editor design and service contract. Student checkpoints begin with the six-product seed; generated API data/control state, dependencies, builds, narration and capture assets are excluded.
