# Connect Saving & Validation Feedback

`Starter/product-explorer` is the incoming project. `product-explorer` is the completed source recorded in this lecture.

The editor submits to its route action, shows field and summary errors, retains rejected values, prevents repeated saves, focuses feedback, and confirms the saved product in inventory.

See Setup.md to run the local app, Code.md for the changes and Reference.md for API links. Fonts, images and their licenses are included. Dependencies, build outputs and generated API data are excluded.
