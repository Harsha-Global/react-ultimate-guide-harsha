# Plan & Set Up ShopFront

Continue the supplied product-explorer project in your React working folder.

## Run locally

1. Run npm ci in the project.
2. Run npm run api in one terminal.
3. Run npm run dev in a second terminal.
4. Open http://127.0.0.1:5185.

The local API uses http://127.0.0.1:4185. Use its supplied reset command only when you intentionally want to restore the seed data.

## Verify

Run npm run check, npm run lint and npm run build.

The existing cart and delivery preferences remain available. Product images and supplied styling are local resources; pages still read the local product array.

Supplied design targets and the service contract are in the Resources folder.
