# Order Desk — Bulk Priority v2 client design kit

Import `Order Desk - Design Kit.fig` into your own Figma Drafts using More → Import → Import from computer. Choose Drafts before importing; the Recents screen may default to a Team folder. The supplied file is a native Figma export. Expand its outer board, select a named screen and use Shift+2 to zoom to it. Text and shapes are editable. PNG/PDF references remain readable independently of Figma.

This revised client kit retains the original screens and adds frames 04/05 for the independent Bulk Order Priority assignment. Frame04 shows BEFORE APPLYING and AFTER THE RESPONSE separately, not simultaneous live panels. A native reusable button component is included.

The brief describes the target workflow developed during the section; it is not a claim that the incoming source already contains every final control. Read the client brief and the Bulk Order Priority assignment instructions alongside the visual frames. The main guided source and the independent assignment solution remain separate.

## Fonts

Use Manrope for headings and DM Sans for body/controls. Local variable TTFs, OFL licenses and original source metadata are in Fonts. Figma offers these matching Google Fonts families. If an SVG import asks for replacements, select the same DM Sans and Manrope families and apply the replacements. The exported native file was checked after those mappings. The native file does not embed font programs; install the supplied licensed fonts only if your environment requires them.
