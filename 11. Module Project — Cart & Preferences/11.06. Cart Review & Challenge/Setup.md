# Run a checkpoint

Choose the completed `product-explorer`, the challenge Starter, or its written Solution. In that project folder run `npm ci` and `npm run dev`, then open the printed local address. `npm run check`, `npm run lint` and `npm run build` verify the source. Each project is independent. Use the supplied `Styles/product-explorer.css` when following the visual layout.

The archive preserves the supplied course folder paths under Practice. The earlier “How to Download Source Code” lesson explains repository access.
