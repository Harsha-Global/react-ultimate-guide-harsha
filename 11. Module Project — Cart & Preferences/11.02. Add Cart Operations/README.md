# 11.02. Add Cart Operations

The completed project adds immutable cart operations, per-product quantity limits and accessible row controls. Filtering products preserves cart lines. The previous 11.01 checkpoint is in Starter/product-explorer. Both projects run independently with npm ci and npm run dev. Use npm run check, npm run lint and npm run build to verify the source. No extra exercise is included. Dependencies, builds, narration and production artifacts are excluded.
