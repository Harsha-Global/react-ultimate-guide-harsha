# 11.05 setup

Use Starter/product-explorer to follow from 11.04, or product-explorer for completed 11.05. In either folder run npm ci and npm run dev; use npm run check, npm run lint and npm run build for verification. Styles/product-explorer.css is the complete prepared stylesheet. This browser stores shopfront-cart-v1 and shopfront-delivery-v1 locally. Use sample details only; deleting those two local-storage entries resets this practice data. No order is placed.
