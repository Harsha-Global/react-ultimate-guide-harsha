R02 — State Tool Choice

Time: about 10 minutes. No AI account or live role-play session is required for this equivalent activity.

Morgan, the team lead, proposes copying the current catalog search into Redux, Zustand and the URL so every feature can find it. The Admin Workspace already uses URL-driven filters, a TanStack Query catalog cache and a small Zustand display-preference store. Your task is to recommend an ownership plan and defend it using observable user behavior.

Respond to these three prompts before reading the sample:

1. Identify the live owner of the unfinished product name, active search/page, fetched catalog rows and display preferences. Explain what Back and a shared link should restore.

2. Recommend a taught state approach for this workspace. Explain why a second query cache or multiple live search copies would add work.

3. Name one genuine tradeoff in your recommendation and a concrete check that would reveal an ownership mistake.

Success criteria: clearly assign all four kinds of state; justify a taught approach from the requirement; identify one genuine tradeoff and a reproducible check. There is no universal winning library.
