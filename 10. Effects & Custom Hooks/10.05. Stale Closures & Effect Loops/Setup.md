# 10.05 setup

To follow along from the previous lesson, open `Starter/focus-desk` in VS Code. For the completed lesson, open `focus-desk`. Every demo and solution is its own independent project. In the chosen project folder, run `npm ci`, then `npm run dev`, and open the local address printed by Vite. Stop the current server with Ctrl+C before switching projects.

The prepared stylesheet is `Styles/focus-desk.css`. Both checkpoint projects already contain the correct stylesheet for their stage.
