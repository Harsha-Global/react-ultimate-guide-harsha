# 10.01 setup

This lecture starts from `Starter/focus-desk`, a new project; do not start from the Section 09 movie project. Open `Starter/focus-desk` in VS Code to follow the lecture, or `focus-desk` to review the finished checkpoint. In each, run `npm ci` once, then `npm run dev`. `Styles/focus-desk.css` is the prepared stylesheet the lecture copies into `src/index.css`; both projects' `src/index.css` already match it byte for byte, so the copy changes nothing.
