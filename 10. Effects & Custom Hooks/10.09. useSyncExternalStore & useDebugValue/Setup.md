# 10.09 setup

Use Starter/focus-desk to follow along from 10.08, or focus-desk for the completed checkpoint. In the selected project folder run npm ci, then npm run dev, and open the local Vite address. The complete prepared CSS is Styles/focus-desk.css.

The network label reports navigator.onLine, not guaranteed website or API reachability. Chrome built-in Network offline simulation may be used to check the badge without reloading the local app while offline. Restore online afterward. React DevTools inspection is optional; the badge works independently of any extension.
