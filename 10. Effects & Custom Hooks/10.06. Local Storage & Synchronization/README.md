# 10.06. Local Storage & Synchronization

`focus-desk` is the completed checkpoint. `Starter/focus-desk` is the previous lecture checkpoint. Open the chosen project in VS Code, run `npm ci`, then `npm run dev`. Use the local address printed by Vite. Stop the server before switching projects.

Choose Focus/Break and a Focus length of 15, 25 or 45 minutes. Both non-sensitive preferences persist across reloads. Invalid stored data recovers to Focus/25. Tasks and remaining countdown seconds are not persisted.

`Styles/focus-desk.css` is the prepared stylesheet. TypeScript, lint and build checks are available through `npm run check`, `npm run lint` and `npm run build`. See Thought Checks.md and Reference Guide.html for review. Dependencies, build output, browser storage and recording files are excluded.
