# 10.07. Custom Hook Design

`focus-desk` is the completed single-panel checkpoint. `Starter/focus-desk` is the previous lecture's completed checkpoint for following along. `Demonstrations/independent-hooks/focus-desk` contains two TimerPanel calls with independent state; only the first enables the global keyboard shortcut. Continue the course from the single-panel main project.

## Run

Open one project folder, run `npm ci`, then `npm run dev`, and open the printed local address. Stop that server before switching projects. `npm run check` checks TypeScript, `npm run lint` checks the source, and `npm run build` creates a production build.

Start the first demo timer while leaving the second stopped. Then start the second and reset the first: the second continues independently. Alt + Shift + P controls only the first panel.

See `Thought Checks.md` and `Reference Guide.html` for review. Dependencies and build output are excluded from this ZIP.
