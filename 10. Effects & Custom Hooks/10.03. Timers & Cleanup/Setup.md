# 10.03 setup

This lecture starts from `Starter/focus-desk`, the completed project of the preceding lecture (10.02. Effect Dependencies); do not start from the Section 09 movie project. Open `Starter/focus-desk` in VS Code to follow the lecture, or `focus-desk` to review the finished checkpoint. In each, run `npm ci` once, then `npm run dev`. `Styles/focus-desk.css` is the prepared stylesheet the lecture copies into `src/index.css`: it is the starter's stylesheet plus the six timer rules (`.timer`, `.time-display`, `.timer-actions`), and `focus-desk/src/index.css` already matches it byte for byte.
