# Preserve a Failed Draft

Complete saveDraft. It receives a draft and an asynchronous send function. Wait for send to finish. On success, return the saved reference, the message "Saved.", and a fresh empty draft. On failure, keep the original name and email, return a null reference, and show the Error message. For a non-Error failure, use "Could not save. Try again.".

Do not change the object passed into the function. A rejected request must not erase the learner's work. The returned state is a small model of the action-result behavior from the lecture; this native exercise does not run a React action or test React pending UI.

Attempt the task before opening the solution. The local Starter and Solution are inside 21. Advanced React & Async UI/Submit Booking with an Action/Practice/C28 - Preserve a Failed Draft.
