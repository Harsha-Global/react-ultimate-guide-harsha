# Callback-ref cleanup

Run this independent copy in `C:\react\callback-cleanup`: `npm ci`, then `npm run dev`. Focus the input, move to the remove button, remove and restore the input, then focus again. The count increases once per focus event. Inspect attach/remove console messages; Strict Mode can deliberately perform an extra setup/cleanup cycle. This is a native-listener demonstration. Use React onFocus for an ordinary app handler. Return to the main project afterward.
