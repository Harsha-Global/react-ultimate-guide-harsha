# Manual assessment rubric

| Criterion | Points | Evidence |
|---|---:|---|
| Required behavior | 40 | The client requirement works and unrelated behavior remains intact. |
| Failure, recovery and boundary checks | 25 | The relevant rejection, retry, state, permission or input boundaries are demonstrated. |
| Reasoning and evidence | 25 | Explain the chosen owner or boundary and report actual checks; use three comparable measurement trials for A13. |
| Clarity and maintainability | 10 | Focused changes, useful naming and no avoidable duplicate state or hidden assumptions. |

Partial credit depends on demonstrated behavior and explanation. A build result alone does not prove the requirement. No private instructor test submission or peer-sharing action is part of this authoring check.
