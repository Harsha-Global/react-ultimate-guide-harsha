# Conditional removal comparison

This independent before-version removes VisitNotes when its button closes the panel. Enter My first bowl, hide the notes and show them again: the draft is empty. The main project instead preserves it with Activity.

Copy this project to a separate Windows folder under C:\react. Run npm ci, then npm run dev. The default page is http://localhost:5210. For the existing notice/review/booking features, run npm run api in another terminal; the notes comparison itself needs no API. Only one API should use4318 at a time. Use separatefrontendports if running both copies together. npm run build and npm run lint check this copy.
