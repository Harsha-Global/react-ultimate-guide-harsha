# Willow House booking studio

Use Node.js with a supported LTS release meeting package.json. Copy this project under `C:\react\booking-studio` on Windows. Run `npm ci`, then `npm run dev`. Open http://localhost:5210. The supplied CSS and licensed local fonts are ready to use. Run `npm run lint` and `npm run build` for source checks. This fictional example does not process payments. No API is required at this stage.
