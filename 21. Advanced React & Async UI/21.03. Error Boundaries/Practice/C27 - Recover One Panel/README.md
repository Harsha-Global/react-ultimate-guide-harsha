# Recover One Panel

Start with the Instructions. Complete the Starter before comparing with Solution. The local companion and native task are the same exercise; a duplicate attempt is optional.

The Native folder holds the React 18 JSX files used by Udemy. The TSX Starter/Solution use the main course’s pinned React 19 setup; this exercise uses APIs supported by both. In either TSX variant run `npm ci`, `npm run dev`, `npm run build`, and `npm run lint`. Test the listed browser behaviors.

Source publication is managed separately. No repository URL has been invented and no source attachment is substituted for that route.
