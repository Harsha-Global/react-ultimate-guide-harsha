Complete parseStockInput(formData) for the local stock editor. Both fields are untrusted, even the hidden id. Return null unless id is exactly P- followed by three decimal digits and stock is a string whose trimmed value contains one or two decimal digits. Otherwise return a new {id, stock} object, with stock converted to a number. Accept zero and 99. Reject missing values, empty text, negatives, fractions, exponent notation and values of 100 or more. Do not mutate FormData. Keep the function name and return type.

This exercise validates input; it does not authorize a user, check whether the product exists, or send a request. Prerequisite: Server Functions & Actions. Allow 10 minutes. The starter incorrectly coerces unchecked fields. Its invalid-input checks must fail until repaired. After your attempt, compare the complete Solution.
