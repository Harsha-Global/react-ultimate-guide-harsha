# Form Submission & FormData

Use the course GitHub repository linked from the “How to Download Source Code” article lecture. Download its ZIP or clone it, then find the section and lecture folder.

**Why handle the form submit event?**

It covers the submit button and keyboard submission. Prevent default navigation, then read currentTarget while handling the event.

**What can FormData.get return?**

A string, File, or null. Narrow actual values; typed state does not validate arbitrary form data.

**Why does the receipt stay Emily after editing David?**

The receipt records the last submitted candidate. Current draft and historical submission are intentionally separate.
