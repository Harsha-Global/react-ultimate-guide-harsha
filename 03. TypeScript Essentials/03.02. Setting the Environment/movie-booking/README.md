# Setting the Environment — lecture-wise source

Create a reproducible local TypeScript project, check it, build JavaScript and run the emitted code with Node.

Keep every src file, package.json, package-lock.json and tsconfig.json together. Edit TypeScript in src. In the project’s Command Prompt, run npm ci for a fresh copy, then npm start. Continue at C:\react\movie-booking. The parent Setup Guide.md explains configuration, recovery and separate demonstration/practice folders.
