# Setting the Environment — practice

Change the ticket count from 2 to 3 in the separate project, then predict, check and run the result.

## Work separately

Copy this complete Practice folder to C:\react\typescript-practice. Open starter in VS Code with its integrated Command Prompt. Run `npm ci` once in that folder, then `npm start` after each edit. Keep the main movie-booking project intact. This is a small follow-along/section challenge, not an additional mapped coding exercise.

## Acceptance criteria

- Only the intended count changes.
- The program reports 3 tickets and total 39.
- The source remains in src; dist is generated.

## Hints

- Edit src/app.ts.
- The fee is added once after multiplying 12 by the count.
