# 02.08. Destructuring — source code

`javascript-essentials/app.js` is the exact saved final main file recorded in this lecture. It keeps the three-product array and all fourteen output messages.

- `Checkpoints/01-Incoming/app.js`: the preceding lecture's starting code.
- `Checkpoints/02-Object pattern/app.js`: the intermediate object-destructuring stage, before naming the three array entries.
- `Demonstrations/skip-entry/app.js`: the separate middle-product comparison.
- `Demonstrations/defaults/app.js`: zero, null, missing-property and missing-entry defaults.
- `Practice/starter/app.js`: complete runnable starter.
- `Practice/solution/app.js`: complete runnable solution; its README explains the changes.
- `Practice/README.md`: the exercise, expected results and instructions.

Run each example independently: open its folder in VS Code, open Command Prompt, and run `node app.js`. No package installation is required. Keep the comparisons and practice separate from the main course project.
