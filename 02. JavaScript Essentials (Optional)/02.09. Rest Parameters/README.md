# 02.09. Rest Parameters — source code

`javascript-essentials/app.js` is the exact saved final main file recorded in this lecture, including both the two-product selection and the empty selection.

- `Checkpoints/01-Incoming/app.js`: the preceding lecture's starting code.
- `Checkpoints/02-Two selected products/app.js`: the intermediate completed selection before adding the empty call.
- `Demonstrations/array-argument/app.js`: compares the outer collected array with the supplied inner array.
- `Demonstrations/rest-position/app.js`: deliberately invalid rest-parameter ordering; running it is expected to report a SyntaxError.
- `Demonstrations/README.md`: comparison instructions and expected results.
- `Practice/starter/app.js`: complete runnable exercise starter.
- `Practice/solution/app.js`: complete solution, with explanation in its README.
- `Practice/README.md`: exercise instructions and expected results.

Run each example independently: open its folder in VS Code, open Command Prompt, and run `node app.js`. No package installation is required. Keep demonstrations and practice separate from the main course project.
