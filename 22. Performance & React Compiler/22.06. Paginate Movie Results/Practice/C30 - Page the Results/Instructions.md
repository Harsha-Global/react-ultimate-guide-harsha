# Page the Results

Complete pageResults. The supplied page size is a positive integer, and the requested page is an integer. Return the requested page of items, the chosen page number, and the number of pages. Clamp the requested page to the available range. For an empty collection, return page 1 of 1 with no items.

Keep the original collection unchanged. This helper limits what the component renders; it does not fetch a server page or make the entire input collection smaller.
