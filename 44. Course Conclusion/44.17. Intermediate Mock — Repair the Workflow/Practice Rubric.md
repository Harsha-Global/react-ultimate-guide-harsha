# Mock interview practice rubric

These weights support learning; they are not an industry hiring standard. Accept equivalent correct solutions with matching evidence.

| Area | Weight | Evidence |
|---|---:|---|
| Clarification | 20 | Identifies the behavior that changes the correct answer; states assumptions |
| Reasoning | 25 | Traces a concrete failure; distinguishes fact from hypothesis |
| Implementation | 25 | Repairs the agreed cause and preserves nearby requirements |
| Verification | 15 | Reproduces the old defect, proves the repair, checks a meaningful boundary |
| Communication | 15 | Gives the answer first, explains relevant evidence, handles follow-ups and limits |

For each area, award full credit for independent, accurate work; partial credit for a useful but incomplete explanation; little credit for unsupported guesses or copied changes the candidate cannot explain. A correction after new evidence is useful reasoning, not automatically a failure. Do not infer a job level from one score.

Beginner: separate row identity from unmount lifetime, preserve blank/zero drafts, verify sort/filter/reset. Intermediate: separate accepted write/read status/draft, guard old responses, retain navigation state and new typing. Senior: establish business identity, trust boundary, concurrency, tenant scope, transaction and rollout limits.

Response practice: pause; state the direct answer or current hypothesis; name the relevant evidence; explain the smallest next action; state one important limit. If interrupted, answer that condition and return to the original question. If unsure, say what is unknown and which observation would resolve it.
