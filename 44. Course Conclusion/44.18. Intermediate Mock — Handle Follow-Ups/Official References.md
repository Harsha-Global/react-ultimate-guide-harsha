# Optional official references

These official pages change over time: check the current documentation when you use them. The lectures do not promise a future release or an industry popularity ranking.

- [AI SDK introduction](https://ai-sdk.dev/docs/introduction), [foundations](https://ai-sdk.dev/docs/foundations/overview), [UI overview](https://ai-sdk.dev/docs/ai-sdk-ui/overview): model integrations and streamed interface state.
- [TanStack DB overview](https://tanstack.com/db/latest/docs/overview), [mutations](https://tanstack.com/db/latest/docs/guides/mutations): collections, reactive queries and persistence handlers; confirm backend acceptance in the chosen integration.
- [Expo create a project](https://docs.expo.dev/get-started/create-a-project/), [core concepts](https://docs.expo.dev/core-concepts/), [React Native core components](https://reactnative.dev/docs/intro-react-native-components): mobile framework and native UI concepts. No old bridge architecture is taught.
- [Effect onboarding](https://effect.website/docs/v4/onboarding), [Effect type](https://effect.website/docs/v4/getting-started/the-effect-type): result, expected error and requirements.
- [Next.js template convention](https://nextjs.org/docs/app/api-reference/file-conventions/template): the root template remounts children when navigating between the editor root and /away; the shared layout/provider above it remains mounted. This is the boundary used in the intermediate mock interview.

The merchant description, stock board, phone photo and import examples are proposed learning exercises, not executed integrations, benchmarks or provider guarantees. No external accounts or paid services are needed for these orientation videos.
