# Practice — Function Components

Extract a PageFooter component in its own file, returning a footer with a paragraph “More movies coming soon.” Import and place it after MovieSummary.

## Expected result

- One page heading and one movie article.
- Footer follows the summary.

## Run and compare

Copy this Practice folder to a separate working location such as `C:\react\practice-04-03`. Open `starter` in VS Code. In its Command Prompt terminal, run `npm ci` once and `npm run dev`. Use the address printed by Vite. `npm run build` checks types and creates the production build. Stop a server with Ctrl+C before switching folders.

Try first. Then inspect `solution`, which contains every required source/configuration/lock file. Run its commands from its own folder. Keep the lecture’s main `movie-discovery` unchanged. These files are prepared for this lecture’s folder in the course GitHub repository.
