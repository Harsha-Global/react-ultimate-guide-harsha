# State Identity

Preserve the chosen quantity when only the layout changes. Reset the quantity to one when the selected showtime changes. Keep the child state inside TicketPicker and preserve the ticket bounds and controls.

Start with `Local/Starter/movie-discovery`. Try the change before opening `Local/Solution/movie-discovery`. Both are complete TypeScript projects. `Native` has the same starter and solution as plain JSX `App.jsx` files. Do not copy JSX into the guided TypeScript project.
