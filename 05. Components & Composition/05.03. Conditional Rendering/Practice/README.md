## Run and compare

Copy this Practice folder to a separate working location such as `C:\react\practice-05-03`. Open `starter` in VS Code. In its Command Prompt terminal, run `npm ci` once and `npm run dev`. Use the address printed by Vite. `npm run build` checks types and creates the production build. Stop a server with Ctrl+C before switching folders.
