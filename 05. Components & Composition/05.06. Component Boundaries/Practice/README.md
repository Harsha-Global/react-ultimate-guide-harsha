# Practice — Component Boundaries

Extend MovieCatalog’s footer to show “Available movies: 1 of 2” for the current data. Derive both values from its movies prop, and test an empty input.

## Expected result

- Current data: Available movies: 1 of 2.
- Empty array: Available movies: 0 of 0; No movies found.

## Run and compare

Copy this Practice folder to a separate working location such as `C:\react\practice-05-06`. Open `starter` in VS Code. In its Command Prompt terminal, run `npm ci` once and `npm run dev`. Use the address printed by Vite. `npm run build` checks types and creates the production build. Stop a server with Ctrl+C before switching folders.

Try first. Then inspect `solution`, which contains every required source/configuration/lock file. Run its commands from its own folder. Keep the lecture’s main `movie-discovery` unchanged. These files are prepared for this lecture’s folder in the course GitHub repository.
