# Event Desk

    Windows: copy this folder to `C:\react\event-registration`. In Command Prompt run `npm ci`, then `npm run dev`. Open http://localhost:5187.

    This first stage demonstrates local form submission only. It does not reserve tickets or contact an API. Run `npm run lint` and `npm run build` for source checks. The prepared CSS and local Manrope/DM Sans font files are included; see public/assets/fonts for licenses. Keep the supplied package-lock.json.
