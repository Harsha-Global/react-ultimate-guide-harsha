# Safe Return Destinations

Start with **Starter/exercise.ts**. Read Instructions.md, attempt the task, and use the named checks to find what still needs work. Hints.md is available if you get stuck. Open Solution only after your attempt.

For a local attempt on Windows, copy this practice folder beneath `C:\react`, open its Starter folder, and run `npm ci`. Then run `npm test`. The test command first checks strict TypeScript and then runs the behavior checks. A failing starter is intentional. `npm run check` runs only the type check. Run the same commands in Solution to check the complete implementation.

This companion and the native exercise count as one activity; a second attempt is optional. The evaluator and test runner are supplied instructor infrastructure. You only need to edit exercise.ts. Both variants deliberately use the native exercise's global declarations so the same evaluation can run locally.

The native runner's accepted TypeScript configuration does not establish strict null safety. This local companion enables strict checking. No package integration or full browser/server workflow is implied by these focused behavior checks. The corresponding lecture project contains that integration.

Find these files through the course source-code route in the How to Download Source Code lecture. Repository publication is managed separately; no URL is invented here.
