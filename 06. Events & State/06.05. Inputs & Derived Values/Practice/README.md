# Practice

Add a $2-per-ticket booking fee. Derive it and include it in total; do not store the fee or total in state.

Try Starter first. Install with `npm ci`, then run `npm run dev` from the copied project folder. Use Solution only after attempting the task. These are complete standalone copies; keep the lecture main project unchanged.

## Acceptance checks

- 2 early tickets: fee $4, total $28.
- 2 late tickets: fee $4, total $34.
- Changing quantity updates both derived values.
